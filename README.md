# E-commerce Platform
This is an e-commerce platform built with Next.js and TypeScript, using GraphQL and PostgreSQL with Hasura for the backend. Currently, only the design has been implemented.

## Getting Started

First, run the development server:

```bash
git clone https://github.com/EseAlli/shop-x.git
```

Install dependencies:
```bash
cd shop-x
yarn install
```

Start the development server:
```bash
yarn dev
```
Open the app in your browser:
```bash
http://localhost:3000/
```
